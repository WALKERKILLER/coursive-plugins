# Security policy

Report vulnerabilities privately through GitHub: open this repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue for a suspected vulnerability.

In scope:

- An index entry whose artifact does not match its source, or that requests permissions or hosts it does not use.
- A mirror in `mirrors.json` that alters content or injects anything into responses.
- Vulnerabilities in an official plugin or in `scripts/`.

Vulnerabilities in a third-party plugin go to its author; tell us as well if the plugin should be removed from the index. Vulnerabilities in the Coursive app go to [Coursive](https://github.com/WALKERKILLER/Coursive/security).

You will receive an acknowledgement within 7 days.
